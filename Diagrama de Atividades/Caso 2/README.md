    <td><h1>Estudo de caso 2</h1>

O usuário solicita ao gerente de TI uma alteração no sistema.

O gerente de TI verifica se o pedido está alinhado ao planejamento estratégico da empresa. Se não estiver, o gerente de TI notifica a recusa ao usuário e não há mais nada a fazer. Se o pedido for aprovado, o gerente de TI envia o pedido para o desenvolvedor que implementará a alteração e, em seguida, encaminha o pedido para o setor de infraestrutura.

O desenvolvedor deverá implementar a alteração e depois fazer a depuração da nova funcionalidade. Paralelamente, o setor de infraestrutura verifica a necessidade de modificar a infraestrutura. Se essa necessidade existir, a infraestrutura será preparada e em seguida será testada.

Somente depois de terminado o trabalho do desenvolvedor e o trabalho do setor de infraestrutura o setor de testes realizará os testes finais. Se os testes mostrarem que o serviço tem a qualidade esperada, o gerente de TI libera a alteração. Caso contrário, o setor de testes notifica o gerente de TI e este faz com que o fluxo do processo volte para o ponto onde ele encaminha o serviço para o desenvolvedor.
